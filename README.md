## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/abubacker8593/PORTFOLIO-REACT.git
```

Navigate into the project

```bash
cd PORTFOLIO-REACT
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```
